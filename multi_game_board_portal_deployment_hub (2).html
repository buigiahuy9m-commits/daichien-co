PRODUCTION DEPLOYMENT CONSOLE

Hướng dẫn triển khai & Bộ mã nguồn hoàn chỉnh kết nối GitHub + Vercel + Neon PostgreSQL Database.

Serverless Stack
BƯỚC 1

Tạo Neon Database

Đăng ký tại neon.tech, tạo project PostgreSQL & copy chuỗi `DATABASE_URL`.

BƯỚC 2

Push GitHub Repo

Tạo Repository mới trên GitHub & push các file `index.html`, `api/index.js`, `package.json` bên dưới.

BƯỚC 3

Import Vercel

Đăng nhập vercel.com, chọn Import Git Repository vừa tạo.

BƯỚC 4

Cấu Hình Env & Deploy

Thêm `DATABASE_URL` vào Environment Variables trên Vercel và bấm **Deploy** để chạy tên miền `.vercel.app`!

schema.sql (Neon PostgreSQL Tables) 
CREATE TABLE IF NOT EXISTS users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    coins INT DEFAULT 1500,
    elo INT DEFAULT 1200,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS matches (
    id SERIAL PRIMARY KEY,
    game_type VARCHAR(20) NOT NULL,
    player_name VARCHAR(50) NOT NULL,
    result VARCHAR(10) NOT NULL,
    bet_amount INT DEFAULT 100,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

api/index.js (Vercel Serverless Function Backend) 
const { Pool } = require('pg');

const pool = new Pool({
    connectionString: process.env.DATABASE_URL,
    ssl: { rejectUnauthorized: false }
});

module.exports = async (req, res) => {
    res.setHeader('Access-Control-Allow-Origin', '*');
    res.setHeader('Access-Control-Allow-Methods', 'GET, POST, OPTIONS');
    res.setHeader('Access-Control-Allow-Headers', 'Content-Type');

    if (req.method === 'OPTIONS') return res.status(200).end();

    try {
        const { action, username, coins, gameType, result, bet } = req.body || req.query;

        // Route: Fetch Leaderboard
        if (action === 'getLeaderboard') {
            const { rows } = await pool.query('SELECT username, elo, coins FROM users ORDER BY elo DESC LIMIT 10');
            return res.status(200).json({ success: true, data: rows });
        }

        // Route: Save Match Result
        if (action === 'saveMatch') {
            await pool.query(
                'INSERT INTO matches (game_type, player_name, result, bet_amount) VALUES ($1, $2, $3, $4)',
                [gameType, username, result, bet]
            );
            return res.status(200).json({ success: true, message: 'Match saved to Neon DB' });
        }

        return res.status(200).json({ success: true, status: 'Neon DB Connected Ready' });
    } catch (err) {
        return res.status(500).json({ success: false, error: err.message });
    }
};
